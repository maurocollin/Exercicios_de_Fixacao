## 🛠️ O que há neste repositório?

Os exercícios estão divididos em dois grandes blocos lógicos, focando em aplicações do mundo real:

### 1. Manipulação de Arquivos (`.txt`) 📄
Exercícios voltados para a persistência de dados e interação com o sistema operacional.
* **Gerador de Tabuada:** Automação de cálculos e escrita em arquivo.
* **Cadastro de Pessoas:** Captura de dados, cálculo dinâmico de idade e armazenamento.
* **Leitura Estruturada:** Transformação de arquivos brutos em listas manipuláveis.
* **Gestão Acadêmica:** Processamento de notas e tomada de decisão (Aprovado/Reprovado).
* **Mini Calculadora Persistente:** Execução de operações matemáticas com log de resultados.

### 2. Manipulação de Strings & Bioinformática 🧬
Exercícios focados no tratamento de cadeias de caracteres e limpeza de dados.
* **Processamento de arquivos:** Inversão de cadeias de caracteres lidas de arquivos.
* **Análise de Texto:** Contagem de palavras e normalização de strings (substituição de caracteres).
* **Tratamento de Repetições:** Algoritmo para extração de palavras únicas em frases, simulando limpeza de bases de dados.

## 🚀 Como testar
Cada script foi projetado para ser executado de forma independente no **Google Colab**.

1. Clone o repositório ou abra o notebook no Colab.
2. Certifique-se de que os arquivos `.txt` de entrada (quando solicitados) foram criados (os scripts possuem blocos de auto-geração para facilitar o teste).
3. Execute a célula de código correspondente ao exercício.

## 🧠 Conceitos Aplicados
* **File Handling:** Modos de abertura (`'r'`, `'w'`, `'a'`).
* **Slicing & Methods:** Manipulação avançada de strings (`[::-1]`, `replace`, `split`).
* **Dicionários e Listas:** Estruturas de dados para organização de resultados.
* **Datetime:** Uso de bibliotecas nativas para cálculos temporais.
